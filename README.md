# 短视频去水印系统（PHP）

一套可直接部署的多平台短视频去水印源码：前台单页解析、完整后台、用户注册登录、点数付费（卡密 + 易支付）。

## 功能特性

- **前台单页**：注册 / 登录 / 粘贴分享内容一键解析 / 预览与下载（视频、背景音乐、图集、备用链接）
- **付费点机制**：每次解析消耗点数，注册赠送体验点数；解析成功后再扣点
- **两种充值方式**：后台批量生成卡密 + 易支付（微信/支付宝）在线充值
- **后台管理**：仪表盘统计、用户管理（加点/扣点/禁用/重置密码）、订单管理、解析记录、卡密管理、站点设置
- **多平台解析**：优先走后台配置的远程接口；未配置时回退内置抖音 / 快手适配器
- **代理下载**：通过 `download.php` 流式转发，解决跨域与防盗链导致无法下载 / 播放的问题
- **安全**：预处理语句、密码哈希、CSRF、登录鉴权、解析频率限制、下载接口 SSRF 防护、登录限流

## 环境要求

- PHP 7.4+（建议 8.0 / 8.1）
- MySQL 5.7+ / MariaDB
- Nginx / Apache
- 必装扩展：`pdo_mysql`、`curl`
- 建议扩展：`fileinfo`、`openssl`、`mbstring`

## 快速开始

1. 完整搭建步骤见 `宝塔部署教程.md`
2. 本地开发：

```bash
# 将网站根目录指向 public
php -S 127.0.0.1:8000 -t public
```

3. 访问 `http://127.0.0.1:8000/install.php` 完成安装
4. 前台：`/` ，后台：`/admin/index.php`
5. 安装完成后立刻删除 `public/install.php`

## 目录结构

```
public/          网站根目录（前台、后台、API、安装向导）
app/             核心代码（配置、数据库、认证、解析框架、支付）
sql/install.sql  数据库初始化脚本
```

## 自定义平台解析

1. 在后台「接口管理」添加远程接口（推荐）
2. 或在 `app/parsers/` 新建解析器并继承 `BaseParser`，系统会在未配置远程接口时回退到内置抖音 / 快手解析器

已内置 `ApiParser` 支持第三方聚合接口。后台填写完整请求地址（末尾以 `url=` 结尾），自动识别抖音 / 快手 / 小红书等平台。

## 安全说明

- `app/config.local.php` 含数据库密码，已加入 `.gitignore`，不要提交
- 下载代理需登录后才能使用，并拦截内网地址
- 状态变更接口带 CSRF 校验；登录 / 注册带 IP 频率限制
- 生产环境关闭 `debug`，接口不再回传内部异常细节

## 说明

- 抖音 / 快手等平台接口会更新，解析失效时优先在后台更换远程接口
- 本站仅提供技术交流，视频版权归原作者所有
