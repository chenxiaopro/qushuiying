# 短视频去水印系统（PHP）

一套可直接部署的多平台短视频去水印源码：前台单页解析、用户中心抽屉、完整后台、点数付费（卡密 + 易支付 + 支付宝当面付）、公众号签到送点。

**完整使用与后台配置说明**：当前工作区 `.monkeycode/docs/使用与配置.md`（项目文档页同步可见）。架构与接口见 `.monkeycode/docs/INDEX.md`。宝塔逐步搭建见 `宝塔部署教程.md`。

## 功能特性

- **前台单页**：注册（用户名+密码）/ 登录 / 粘贴分享内容一键解析 / 预览与下载（视频、背景音乐、图集、实况、备用链接、文案复制）
- **用户中心**：首页侧边抽屉，概览 / 解析记录（只读）/ 充值记录 / 设置（补绑邮箱、改密）；微信绑定码直接显示在概览
- **付费点机制**：每次解析成功后扣点；注册赠送体验点数；公众号每日签到只加余额、不计入累计充值
- **三种充值**：后台批量卡密、易支付（微信/支付宝等跳转）、支付宝当面付扫码
- **后台管理**：仪表盘、解析类型、接口管理、卡密、用户（加点/扣点/禁用/重置密码/改邮箱/解绑微信）、订单、解析记录、历史版本、站点设置
- **多平台解析**：优先走后台「接口管理」远程接口；未配置时回退内置抖音 / 快手适配器
- **公众号**：首页关注弹窗（独立开关）+ 功能栏「每日签到」（绑定码发给公众号）
- **其它**：微信/QQ 分享卡片、Bark 注册/充值通知、下载代理防盗链、历史版本自动升号

## 环境要求

- PHP 7.4+（建议 8.0 / 8.1）
- MySQL 5.7+ / MariaDB
- Nginx / Apache
- 必装扩展：`pdo_mysql`、`curl`
- 建议扩展：`fileinfo`、`openssl`、`mbstring`

## 快速开始

1. 完整搭建与配置步骤见 `宝塔部署教程.md`
2. 本地开发：

```bash
# 将网站根目录指向 public
php -S 127.0.0.1:8000 -t public
```

3. 访问 `http://127.0.0.1:8000/install.php` 完成安装
4. 前台：`/` ，后台：`/admin/index.php`
5. 安装完成后立刻删除 `public/install.php`
6. 生产环境在 `app/config.local.php` 填写 `site_url` 为 `https://你的域名`

## 后台配置速查

登录后台 →「站点设置」：

| 区块 | 作用 |
|------|------|
| 基础设置 | 站名、公告、解析扣点、注册赠点、1 元兑点数 |
| 公众号弹窗引导 | 首页二维码弹窗（关后 7 天不再显示） |
| 公众号签到 | AppID / Secret / Token、每日点数、服务器 URL `/wxmp.php`、创建菜单 |
| 微信 / QQ 分享卡片 | OG 标题、描述、封面 |
| 易支付 | RSA 密钥、支付方式、回调 `/pay_notify.php` |
| 支付宝当面付 | AppID、RSA2 密钥、通知 `/alipay_notify.php` |
| Bark | 注册/充值推送到管理员手机 |

解析能力在「解析类型」+「接口管理」配置，不在站点设置里。远程接口地址须带 `url=`，slug 填平台或 `*`。前台选「短视频/图集解析」时远程 `type` 为 `dsp`；自动识别时按平台映射（小红书 `xiaohongshu`，其余 `dsp`）。

用户侧：登录后打开用户中心概览，复制 6 位绑定码发给公众号，即可每日点「每日签到」领点。开关打开就会自动出码，不必先填齐 AppID。创建菜单仍需 AppID、Secret、Token 齐全。

## 目录结构

```
public/          网站根目录（前台、后台、API、安装向导、支付/公众号回调）
app/             核心代码（配置、数据库、认证、解析框架、支付、公众号）
sql/install.sql  数据库初始化脚本
```

## 自定义平台解析

1. 在后台「接口管理」添加远程接口（推荐）
2. 或在 `app/parsers/` 新建解析器并继承 `BaseParser`，系统会在未配置远程接口时回退到内置抖音 / 快手解析器

已内置 `ApiParser` 支持第三方聚合接口。后台填写完整请求地址（query 含 `url=`）。请求时会按前台解析类型把远程 `type` 写成对应产品编码（如短视频/图集 `dsp`），自动识别时小红书用 `xiaohongshu`、其余用 `dsp`，不会把 `custom` 原样带出去。

## 安全说明

- `app/config.local.php` 含数据库密码，已加入 `.gitignore`，不要提交
- 下载代理需登录后才能使用，并拦截内网地址
- 状态变更接口带 CSRF 校验；登录 / 注册带 IP 频率限制
- 生产环境关闭 `debug`，接口不再回传内部异常细节

## 说明

- 抖音 / 快手等平台接口会更新，解析失效时优先在后台更换远程接口
